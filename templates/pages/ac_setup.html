Important: Keep synced with physical AC

For machine-learning data to be accurate, the values selected here must match the actual settings on the air conditioner.

  • Set the AC Status here to the same mode currently active on the physical AC (use the numeric codes 1–6 shown).
  • Set the AC Thermostat here to the same numeric level (1–10) as the physical thermostat.
  • If the UI and the physical unit differ, collected telemetry will be mislabeled and harm model training.

When you change settings on this page, also change the AC itself to the same values before collecting data.
